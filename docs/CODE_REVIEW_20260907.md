## 历史事实与重跑边界

报告所说“test每轮可见”证明公开接口不符合严格封存测试语义，不能单独证明test参与了某次模型选择。
报告中的训练数据总数、外部recall、Score样本数等仅作为待核查历史声明，本轮未据此重写论文数值。
本地公开副本缺少可串联的 `CURRENT_RELEASE.json`、实验登记表与数值映射，因此不在本轮认定任何新的当前模型。

CTC守卫会在原来静默置零的样本处停止，这属于预期变化；请先用审计脚本生成明确的训练/验证loss纳入清单。
其余不支持的最终评估谱图必须仍进入recall分母。是否重训应由真实审计与逐epoch重算决定。
