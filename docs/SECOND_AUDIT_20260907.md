## 已确认并修复的问题

| 编号 | 优先级 | 触发及影响 | 修复与证据 |
|---|---|---|---|
| A2-01 | P1 | 仅一个有效候选时，`_selected` 的 runner-up 不存在，margin 为 inf。上一轮使用 -inf 屏蔽填充项后，带填充的单候选也会出现该问题。非有限特征可使路由概率成为 NaN，而原逻辑可能静默回退 R1。 | 单候选margin定义为0，并直接保留R1，不调用路由网络。多候选路由前检查特征有限性。测试覆盖单候选独立批次和混合批次，确保只对真正需要选择的行执行路由。 |
| A2-02 | P1 | `--config` 的 max_charge、residues 或预处理设置用于输入/评估，实际神经推理却仍读模型缓存配置，造成同一次运行使用两套设置。 | 外部推理YAML只允许 runtime 操作参数覆盖；修改冻结字段时立即报错。输入和评估均引用冻结配置，训练自定义配置不受此限制。 |
| A2-03 | P2 | 命令行已验证索引类型，但直接调用 `predict_lmdb(indices=[1.9])` 会先转int64，再验证，实际变成索引1。 | 删除验证前的整数强制转换，统一在 IndexedDataset 中验证原始类型、范围和唯一性。 |
| A2-04 | P1 | 输出迭代器提前结束时，CLI仍替换原输出并声明complete；重复/乱序输出也缺少显式检查。 | 按预期输入索引逐行检查，并在替换文件前确认行数完全相符。缺少、多余、重复或乱序输出均报错，保留已有结果文件。 |
